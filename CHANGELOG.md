# Changelog

## 1.0 — Public source release

- Public source distribution for Zetalvx Image Lab — SDXL Edition.
- Local SDXL generation, Img2Img and inpainting workflows.
- Checkpoint and LoRA management.
- Dataset workspace and SDXL LoRA training.
- Vision-assisted captioning with local/API backends.
- InstantID / Face Consistency and Face Swap workflows.
- Projects, library, presets, jobs and media tools.
- Linux and Windows manual source setup.
- Separate Source data home to avoid modifying packaged installations.

Release-specific implementation details are tracked through Git history and pull requests rather than embedded private build notes.
