# Models and licenses

Zetalvx Image Lab does not bundle model weights in the Source repository.

The application can work with SDXL checkpoints, LoRAs, optional Identity/Face components and Vision models supplied or downloaded separately by the user. Each model retains its own license and usage terms.

SDXL Base can be downloaded explicitly after the user accepts its model license. External checkpoints and LoRAs may use different licenses. InstantID, InsightFace pretrained models, Face Swap models and Vision models must be reviewed individually.

A downloader, file picker or successful model load is a technical capability, not a license certification. The application’s Apache-2.0 license does not grant additional rights over third-party model weights or user media.
